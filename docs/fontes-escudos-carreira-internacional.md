# Escudos oficiais acrescentados para a carreira internacional

Os 21 arquivos em `public/escudos-clubes/` completam as 72 instituições da
carreira. Foram reduzidos a WebP de até 160 px e mantidos fora do bundle.
O índice correspondente fica em `src/escalacao/escudos-internacionais.ts`.

| Fonte pública | Instituições | Arquivos originais |
|---|---|---|
| [FCLOGO/fclogo.top](https://github.com/FCLOGO/fclogo.top/tree/main/src/data/logos/AFA/clubs) | Argentinos Juniors, Estudiantes, Independiente, Newell's Old Boys, Racing, Rosario Central, San Lorenzo | `src/data/logos/AFA/clubs/<clube>/png/` (versões coloridas) |
| [RanuK12/GambetaGame](https://github.com/RanuK12/GambetaGame/tree/main/public/logos/carrera) | Peñarol, Nacional, Olimpia, Colo-Colo, Cerro Porteño, Libertad, Millonarios, Universitario | `public/logos/carrera/` (arquivos nomeados pelo clube) |
| [mierzida/FLP_forBBK](https://github.com/mierzida/FLP_forBBK/blob/main/public/assets/logos/colombia/america-de-cali.svg) | América de Cali | `public/assets/logos/colombia/america-de-cali.svg` |
| [sportlogos/football.db.logos](https://github.com/sportlogos/football.db.logos) | Emelec, Feyenoord, Galatasaray, Anderlecht, Shakhtar Donetsk | `south-america/ec-ecuador/emelec.png`; `europe/nl-netherlands/feyenoord.png`; `europe/tr-turkey/galatasaray.png`; `europe/be-belgium/anderlecht.png`; `europe/ua-ukraine/donezk.png` |

O escudo de Shakhtar foi conferido no arquivo `donezk.png` (a imagem traz
“Шахтар”). Os escudos do clube criado pelo usuário continuam independentes
dos escudos dessas instituições.
